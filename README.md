# Python Internship Projects

This repository contains Python programs developed as part of my internship tasks.
The projects demonstrate basic programming concepts such as conditional statements, loops, string manipulation, regular expressions, and CLI-based applications.

## Tasks Included

### Task 1 – Password Strength Checker

A Python program that checks whether a password is strong or weak.
It validates:

* Minimum password length
* Presence of uppercase letters
* Presence of numbers
* Presence of special characters
  This task uses **string manipulation and the `re` (regex) module**.

### Task 2 – Simple CLI Chatbot

A rule-based chatbot built using Python.
The chatbot responds to greetings and common questions using **if-elif statements** in a command-line interface.

### Task 3 – Number Guessing Game

A CLI-based game where the user tries to guess a randomly generated number.
The program gives hints such as whether the guess is close or far and counts the number of attempts.

### Task 4 – CLI Calculator

A simple command-line calculator that performs basic arithmetic operations:

* Addition
* Subtraction
* Multiplication
* Division

The program continuously accepts user input until the user exits.

## Technologies Used

* Python
* Regular Expressions (`re` module)
* Random module
* Datetime module
* Command Line Interface (CLI)
